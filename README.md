** Jarvis Voice Assistant

A beginner Python voice assistant built to take voice commands, speak responses, open websites, and play songs from a local `musiclibrary` module.

** Features
- Voice command recognition using `speech_recognition`
- Text-to-speech replies using `pyttsx3`
- Quick browser shortcuts (`Google`, `YouTube`, `ChatGPT`, `Brave`, `Facebook`, `VLC`)
- Play tracks from `musiclibrary.py`

** Tech Stack
- Python
- `speech_recognition`
- `pyttsx3`
- `webbrowser`

** How to Run
1. Clone or download the repository.
2. Install required libraries:
   ```bash
   pip install speechrecognition pyttsx3
